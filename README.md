# 🏠 House Price Prediction App

A Machine Learning web app built using Streamlit to predict house prices based on property features.

## 🚀 Features

* Predict house price using ML model
* Clean and interactive UI
* Multi-page app (About, Insights)
* Real-time predictions

## 🛠 Tech Stack

* Python
* Pandas
* Scikit-learn
* Streamlit

## ▶️ Run Locally

pip install -r requirements.txt
streamlit run app.py
